10 NEW LEGENDARY WIZARD GEAR SETS

Produced from the newly attached wizard kit using its material, pattern and emblem recipe workflow. All five pieces retain the source sculpt folds and stitching. The model silhouette is unchanged.

Each set ZIP in sets/ is the unchanged make_set.py export. It contains a 2048-square color.jpg atlas, set.json, a before/after preview, the recipe and every referenced source picture. Extract this collection and use the individual set ZIPs for import.

Intended rarity: legendary. Assign item rarity during game integration; the kit does not provide a rarity importer field. Palette assignments are alternative looks for the same palette, and can be rebound to individual items during integration.

Each archive contains its ten newly created sets only.
