TEN UNCOMMON WIZARD SKINS WITH DISTINCT EMBLEMS AND DESIGNS

All ten sets contain five pieces: hat, mantle, tunic, legs and boots. Each set has its own original pictorial embroidered badge, body-space color layout, finished borders, fine embroidery and reinforced leather. The silhouette follows the kit model.

Rarity: uncommon. The kit does not encode rarity as an importer field; uncommon intent is recorded in each set blurb. Assign rarity during game item integration.

Each unchanged individual ZIP was produced by the supplied make_set.py. It contains the 2048 x 2048 color map, set.json, before/after four-angle preview, and complete recipe/painted skins/decal sources for rebaking with the kit.

Extract this collection and import the individual ZIPs from sets/. Palette bindings are alternative looks; choose a set per palette or bind to individual items in the game integration. No game repository has been modified.

Gloamwing (gloamwing_uncommon); palette: amethyst; emblem: moth. A dark plum center panel, pale folded cuffs, scalloped hem embroidery and pewter edging.

Stoneback (stoneback_uncommon); palette: ash; emblem: tortoise. Sage panels, slate quilted shoulders, linked rectangular borders and pewter knee edging.
Glassfen (glassfen_uncommon); palette: night; emblem: dragonfly. Indigo with moss shoulder panels, a narrow pale placket, paired cuff rings and silver-thread dashes.
Thistleguard (thistleguard_uncommon); palette: amethyst; emblem: thistle. Heather cloth framed by a dark green bib, small embroidered florets and steel-toned binding.

Moonthread (moonthread_uncommon); palette: night; emblem: crescent moon. Midnight cloth with a pale curved front panel, small hem dots and double pewter piping.

Starwake (starwake_uncommon); palette: night; emblem: comet. Cobalt and mulberry stepped panels, offset sleeve bands and small silver-tone stud rows.
