# Bellmourn — Interior walls, 051–070

Twenty color textures for living chambers: plaster, wood, woven wall coverings, and embossed leather. CATALOG.json records the exact ImageGen prompts and hashes. CONTACT_SHEET.jpg is a visual index.

Native 1254 × 1254 PNG color maps, generated using built-in ImageGen. No normal, roughness or height maps are included. Seamless tiling was requested, but opposite edges can mismatch: these have not been repaired or certified seamless under ordinary repeat. Test each in your engine; mirrored repeat can reduce discontinuities but introduces symmetry.

All PNGs were decoded and checked for duplicate hashes. Edge statistics are diagnostics, not proof of seamlessness. No engine import test was performed.
