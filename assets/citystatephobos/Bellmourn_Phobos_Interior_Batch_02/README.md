# Castle Velscour — living chambers, batch 02

Ten generated color textures, numbered 041–050 to follow batch 01. See CATALOG.json for names, descriptions, exact generation prompts, dimensions and hashes. CONTACT_SHEET.jpg shows the set.

Generated with the built-in ImageGen tool. All images are original native 1254 × 1254 PNGs, despite a 2048 request. These are color maps only; no PBR maps are included and some lighting is baked in.

The images were prompted to tile, but edge measurements show mismatches; ordinary repeat is not guaranteed seamless. Mirrored repeat can hide color discontinuities but produces symmetric patterns. Inspect in your engine before use. Separate images have different joint layouts and are not edge-matched interchangeable variations. This batch explores ten individual materials, so each brick type has one variation; additional variants are needed to satisfy the original four-per-pattern target.

All PNGs decoded successfully and all hashes are distinct. Edge metrics are diagnostics, not proof of visual seamlessness. No in-engine testing performed.
