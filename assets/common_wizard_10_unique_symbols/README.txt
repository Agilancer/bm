TEN COMMON WIZARD SKINS WITH DISTINCT EMBLEMS AND DESIGNS

All ten sets contain five pieces: hat, mantle, tunic, legs and boots. Each set has its own original pictorial stitch badge, body-space color layout and material combination. The silhouette follows the kit model.

Each unchanged individual ZIP was produced by the supplied make_set.py. It contains the 2048 x 2048 color map, set.json, before/after four-angle preview, and complete recipe/painted skins/decal sources for rebaking with the kit.

Extract this collection and import the individual ZIPs from sets/. Palette bindings are alternative looks; choose a set per palette or bind to individual items in the game integration. No game repository has been modified.
