COMMON WIZARD GEAR — SIX SETS

Each set ZIP is an unchanged, self-contained kit export, including color.jpg, set.json, before/after preview and rebake source. Extract this collection and import the individual set ZIPs.

Hedgeway Common Gear (hedgeway_common): Ashen palette; brown wool and saddle leather.
Hearthash Common Gear (hearthash_common): ash palette; Undyed oatmeal wool, charcoal mantle and worn brown leather.
Reedwalker Common Gear (reedwalker_common): moss palette; Faded olive twill, dark moss shoulders and weathered saddle leather.
Rainward Common Gear (rainward_common): night palette; Weathered slate-blue cloth, darker shoulders and soot-brown boots.
Clayroad Common Gear (clayroad_common): crimson palette; Dusty brick-red wool, dark russet mantle and chestnut leather.
Duskfield Common Gear (duskfield_common): amethyst palette; Faded heather cloth, dark plum shoulders and plain brown leather.

Hedgeway and Hearthash are alternative looks for the Ashen palette. Both target all Ashen shapes; choose one when assigning that palette in-game, or adjust the recipe bindings and rebake. No in-game integration was performed.
