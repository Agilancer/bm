# Lines to rewrite: what the voice critics' rules sent back

Written from `tools/voice/shipped.json` after the full recording run (2026-11-10). Every line here is **in the game**
already, with its best take. The rule (docs/VOICES.md) is that a line needs **two** takes that pass, so a lucky one-off
isn't mistaken for a line the voice can say. These didn't get two, after all their takes (8, or 16 for orders, calls and
shouts), so the critics' answer is new words, not another run of the same ones.

- **No passing take:** the game has the take that missed the fewest rules. The last column says what it misses.
- **One passing take:** the game has that take, which passed every rule. The line is here because one pass isn't two.

New words are the owner's call. When a line is rewritten, its key changes, so only it is recorded again
(the commands in docs/VOICES.md).
